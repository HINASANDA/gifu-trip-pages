# 岐阜旅行しおり

岐阜旅行用のしおり。紙はやはり効率悪いのでこっちに避難したよ。許してｸﾚﾒﾝｽ

## ファイル

- `index.html`：画面の構造
- `style.css`：デザイン・スマホ対応
- `script.js`：日程、支出管理、天気、マップ、保存機能

## 主な機能

- 5日間の日程切り替え
- 次の予定表示
- 日程内と専用タブからGoogleマップを開く
- Open-Meteoによる日別天気・最高最低気温・降水確率
- 予定上の交通費・宿泊費集計
- 実際に使ったお金の記録・分類別集計
- 持ち物チェック・自由メモの端末保存
- ダークモード

## GitHub Pagesで公開する方法

1. このフォルダ内の3ファイルをリポジトリ直下へアップロードします。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選択します。
4. Branchを `main`、フォルダを `/(root)` にして保存します。
5. 表示されたURLをスマートフォンで開きます。

天気表示にはインターネット接続が必要です。支出・チェック・メモは、入力したブラウザのローカルストレージに保存されます。
